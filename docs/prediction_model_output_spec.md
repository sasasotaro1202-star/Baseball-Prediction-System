# 予測出力仕様(サッカー・野球)

このファイルは `prediction_model_specification.md`(特徴量・データ仕様)の**出力フォーマット追補**。両方合わせて必ず参照すること。

## サッカー

### 対象大会(必須・全カバー)
- 欧州五大リーグ: Premier League, Bundesliga, Serie A, La Liga, Ligue 1
- Eredivisie(オランダリーグ)
- DFB-Pokal(一部、全ラウンドではなく対象範囲を限定)
- UEFA Champions League(UCL)
- UEFA Europa League(UEL)
- Jリーグ: J1, J2, J3 全カテゴリ

### 引き分け(Draw)の判定ルール
1X2予測におけるDraw判定は**必ずレギュレーション(90分+ロスタイム、延長戦前)の結果**を基準にする。

- 延長戦で決着がついた場合 → **Draw**として扱う(90分終了時点で同点だったため)
- PK戦まで進んだ場合 → **Draw**として扱う(90分・延長戦とも同点だったため)
- 延長戦が行われず90分で試合終了した場合の同点 → **Draw**

つまり、勝敗ラベルは常に「レギュレーションタイム終了時点のスコア」で確定し、延長戦・PK戦の勝者情報は1X2予測のターゲットラベルには使用しない。

### 出力する予測項目
1. **MOM(Man of the Match)予測**: 3択、確率を%表示。3択の合計が100%になる必要はない。
2. **スコア予測**: 4択、確率を%表示。4択の合計が100%になる必要はない。

## 野球(NPB・MLB)

### 対象試合
NPB・MLBの全試合(両リーグ、全シーズン)。

### 出力する予測項目
1. **スコア予測**: 4択まで絞り、確率を%表示。100%になる必要はない。
2. **ロースコア/ハイスコア判定**:
   - Low = 両チーム合計6点以下
   - High = 両チーム合計7点以上
   - それぞれの確率を%表示。

## 共通の注意点
- 確率の合計を100%に正規化する必要はない(各選択肢は独立した信頼度スコアとして出力する)。
- この出力仕様は `prediction_model_specification.md` の特徴量・モデル構造(Elo, xG, Statcast, オッズ等)と組み合わせて使用する。
- 未来情報を使ったリーク(延長戦・PK戦の結果をレギュレーション時点のDraw判定に混入させる等)は禁止。
